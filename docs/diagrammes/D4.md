# D4 — États-transitions : Cycle de vie d'un exercice

*(Diagramme bonus)*

```mermaid
stateDiagram-v2
    [*] --> DEPOSE : Étudiant soumet l'URL (ou la remplace)
    
    DEPOSE --> EN_ATTENTE : Le système assigne 1 ou 2 relecteurs au hasard (RG12)
    
    EN_ATTENTE --> EN_ATTENTE : 1er des 2 relecteurs rend sa note (définitive, RG7) - note provisoire affichée (RG13)
    
    EN_ATTENTE --> EVALUE : 2e relecteur rend sa note - EVALUE, note = moyenne (RG12)
    
    EVALUE --> [*]
```

> **Révisé étape 3 (RG12/RG13) :** avant, `EN_ATTENTE → EVALUE` se faisait en une seule transition (1 seul relecteur). Maintenant `EN_ATTENTE` a une auto-transition pour la 1ʳᵉ des 2 relectures reçues (note provisoire, exercice pas encore `EVALUE`) avant la transition finale vers `EVALUE` à la 2ᵉ.
