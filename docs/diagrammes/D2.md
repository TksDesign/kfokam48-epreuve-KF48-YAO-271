# D2 — Diagramme de Classes / Modèle de Données

Ce diagramme décrit les entités de l'application et leurs relations. Il doit servir de base stricte pour les migrations de base de données (Flyway/Liquibase).

```mermaid
classDiagram
    class Promotion {
        +Long id
        +String nom
    }
    
    class Etudiant {
        +Long id
        +String nom
        +Long promotionId
    }
    
    class Session {
        +Long id
        +String titre
        +String code
        +DateTime ouvertureAt
        +DateTime expirationAt
        +Boolean cloturee
        +Long promotionId
    }
    
    class Presence {
        +Long id
        +DateTime date
        +String source
        +Long sessionId
        +Long etudiantId
    }
    
    class Exercice {
        +Long id
        +String lien
        +String statut
        +Long sessionId
        +Long auteurId
        +Long relecteurId
    }
    
    class Relecture {
        +Long id
        +Integer note
        +String commentaire
        +DateTime date
        +Long exerciceId
    }
    
    Promotion "1" -- "*" Etudiant
    Promotion "1" -- "*" Session
    
    Session "1" -- "*" Presence
    Etudiant "1" -- "*" Presence
    
    Session "1" -- "*" Exercice
    Etudiant "1" -- "*" Exercice : auteur
    Etudiant "1" -- "*" Exercice : relecteur
    
    Exercice "1" -- "0..1" Relecture
```
